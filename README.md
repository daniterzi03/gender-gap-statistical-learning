# Gender Gap Classification with Statistical Learning

## Overview
This project applies statistical-learning and classification methods in R to country-level labour-market and development indicators related to gender disparities.

The objective is predictive rather than causal: compare how alternative classifiers discriminate between observations with relatively larger and smaller employer gender gaps.

## Workflow
- Data cleaning and feature engineering
- Binary target construction
- Train/test split
- Class-balance diagnostics
- SMOTE for selected models
- Standardization
- Model comparison
- ROC/AUC and confusion-matrix evaluation

## Models
- Logistic regression
- Stepwise logistic regression
- LDA and QDA
- Naive Bayes
- Ridge and Lasso
- Generalized Additive Models
- Polynomial logistic regression

## Repository Structure
- `gender_gap_classification.R` — complete R analysis
- `data/gender_gap.xlsx` — project dataset

## Skills Demonstrated
Classification · SMOTE · Regularization · LDA/QDA · ROC/AUC · Nonlinear modelling · Feature engineering · R

## Interpretation
This is a predictive/statistical-learning exercise. Predictors should not be interpreted as causal determinants of gender inequality.
